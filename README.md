# 血浆 CPN2 与肝病的孟德尔随机化

检验血浆 CPN2 蛋白水平是否因果影响 非酒精性脂肪肝 → 肝硬化 → 肝细胞癌,
并反向检验肝病/肝脏脂肪是否因果改变血浆 CPN2。

## 结论(2026-09-15)

**双向都没有找到因果证据。**

| 方向 | 证据 | 结论 |
|---|---|---|
| CPN2 → 肝病 | MR(3 cis-pQTL)+ 共定位 | 无因果证据;**位点上根本不存在肝病信号** |
| 肝病 → CPN2 | 反向 MR,FinnGen NAFLD(3 IV) | 无因果证据,风险翻倍对应变化 < 0.04 SD |
| 肝脂 → CPN2 | 反向 MR,UKB 肝脏 MRI(8 IV,无偏扫描) | 无因果证据;异质性可由脂质多效性位点解释 |

共定位显示:**CPN2 位点上根本不存在肝病的遗传关联信号** —— ±500 kb
区域内结局端最强关联 P ≈ 1×10⁻³,离全基因组显著线(5×10⁻⁸)差五个数量级。
因此 MR 中 NAFLD 那个边缘显著(P = 0.040)不应解读为阳性。

⚠ 本结论只针对**血浆中游离、适配体可及的 CPN2 总量** —— 这是 SomaScan 测量的对象。
它不排除疾病状态改变 CPN2 在游离态与 EV 结合态之间的**分配比例**:那种变化不改变
总量,MR 在结构上就看不到。

## 结果

### 正向 MR:血浆 CPN2 → 肝病(TwoSampleMR 0.7.9)

主分析为 IVW。「剔除 PAV」一版排除了带蛋白改变变异的 rs3732477。

| 结局 | 方法 | n | OR | 95% CI | P |
|---|---|---|---|---|---|
| **非酒精性脂肪肝** | IVW | 3 | 1.108 | 1.005–1.222 | **0.040** |
| | MR-Egger | 3 | 1.131 | 0.975–1.311 | 0.350 |
| | 加权中位数 | 3 | 1.110 | 1.008–1.223 | 0.033 |
| | 加权众数 | 3 | 1.110 | 1.000–1.231 | 0.188 |
| | *IVW(剔除 PAV)* | 2 | *1.012* | *0.502–2.040* | *0.972* |
| **肝硬化** | IVW | 3 | 1.061 | 0.981–1.147 | 0.137 |
| | MR-Egger | 3 | 1.068 | 0.950–1.202 | 0.470 |
| | 加权中位数 | 3 | 1.062 | 0.983–1.147 | 0.130 |
| | 加权众数 | 3 | 1.062 | 0.981–1.149 | 0.274 |
| | *IVW(剔除 PAV)* | 2 | *1.000* | *0.572–1.748* | *0.999* |
| **肝细胞癌** | IVW | 3 | 0.946 | 0.752–1.190 | 0.636 |
| | MR-Egger | 3 | 0.969 | 0.596–1.577 | 0.921 |
| | 加权中位数 | 3 | 0.950 | 0.783–1.152 | 0.599 |
| | 加权众数 | 3 | 0.952 | 0.786–1.153 | 0.666 |
| | *IVW(剔除 PAV)* | 2 | *0.624* | *0.071–5.469* | *0.670* |

四种方法方向一致。**MR-Egger 截距**均不显著(P = 0.78 / 0.90 / 0.92),无定向多效性证据;
**Cochran Q** 均不显著(P = 0.86 / 0.96 / 0.23),无异质性证据。

脂肪肝的 IVW 与加权中位数虽落在 P < 0.05,但**剔除 rs3732477 后 P 升至 0.97**。
该变异单独占 IVW 约 98% 的权重,因此这一结果不应视为阳性 —— 共定位进一步支持这一判断。

### 贝叶斯共定位(coloc 5.2.3)

窗口为 CPN2 TSS ± 500 kb,两端共有变异约 4,000 个。

| 结局 | PPH0 | PPH1<br>*仅蛋白* | PPH2<br>*仅疾病* | PPH3<br>*不同因果变异* | **PPH4**<br>*共享因果变异* | 区域内结局最强关联 |
|---|---|---|---|---|---|---|
| 非酒精性脂肪肝 | 0.000 | **0.766** | 0.000 | 0.153 | **0.081** | P = 1.2×10⁻³ |
| 肝硬化 | 0.000 | **0.817** | 0.000 | 0.158 | **0.025** | P = 9.6×10⁻⁴ |
| 肝细胞癌 | 0.000 | **0.757** | 0.000 | 0.223 | **0.020** | P = 1.7×10⁻³ |

**PPH1 占主导(0.76–0.82)的含义**:暴露端(CPN2)在该区域有明确信号,而结局端没有。
±500 kb 内肝病的最强关联 P 约 1×10⁻³,离全基因组显著线(5×10⁻⁸)差五个数量级。

这说明问题不是「效应太小没测出来」,而是**该位点本身不是肝病风险位点**。

### 反向 MR:肝病 / 肝脂 → 血浆 CPN2

正向阴性只说明「CPN2 不致病」,不排除「疾病改变 CPN2」。反向做了两版,
用**不同的暴露数据源与表型定义**互相印证。

> ⚠ 反向设计里 CPN2 是**结局**,结局端不需要工具变量 —— 正向那个「只有 3 个
> cis-pQTL 可用」的限制在此不适用。暴露端工具变量相对 CPN2 全部是 trans,
> 且无需达到显著。

#### A · FinnGen R12 NAFLD → CPN2(3 个工具变量)

| 方法 | n | β(CPN2 SD / log-odds) | SE | P |
|---|---|---|---|---|
| **IVW** | 3 | **0.0034** | 0.0292 | **0.908** |
| MR-Egger | 3 | −0.0180 | 0.1017 | 0.889 |
| 加权中位数 | 3 | −0.0069 | 0.0200 | 0.731 |
| 加权众数 | 3 | −0.0182 | 0.0213 | 0.484 |

Cochran Q = 5.67(P = 0.059);Egger 截距 P = 0.857。
95% CI 为 −0.054 到 0.061,即**患病风险翻倍对应 CPN2 变化不超过 ±0.04 SD**。
这一版不是功效不足,是能排除实质效应。

**GCKR 作反面教材**:rs1260326 对 NAFLD 只有 P = 5.4×10⁻⁶(够不上工具变量),
但对 CPN2 是 P = 1.8×10⁻¹³、Wald ratio 0.569 —— 是其他位点的 7–25 倍。
强行纳入后 Cochran Q 从 5.67 飙到 **56.65(P < 1×10⁻¹¹)**。脚本里保留为敏感性分析。

#### B · UK Biobank 肝脏 MRI 脂肪含量 → CPN2(8 个工具变量,全基因组无偏)

改用连续表型 + 全基因组扫描(746 个显著变异,±1 Mb 距离剪枝后 8 个独立位点):

| 分析 | n | IVW β | SE | P | Cochran Q |
|---|---|---|---|---|---|
| 主分析:全部 | 8 | 0.0952 | 0.0844 | 0.259 | **49.3, P = 2×10⁻⁸** |
| A:剔除 ADH1B(酒精通路) | 7 | 0.0961 | 0.0913 | 0.292 | **49.1, P = 7×10⁻⁹** |
| **B:再剔除 APOE + TRIB1** | 5 | **0.0330** | 0.0586 | **0.573** | 11.4, P = 0.023 |

敏感性 B 的 95% CI 为 −0.082 到 0.148(CPN2 SD / 肝脂 SD),Egger 截距 P = 0.921。

**异质性有结构,不是噪声。**各位点单独的 Wald ratio:

| 位点 | 基因 | Wald ratio | 95% CI | 性质 |
|---|---|---|---|---|
| rs112875651 | **TRIB1** | **1.047** | 0.715, 1.378 | 肝脏转录总闸门(C/EBPα 通路) |
| rs2642438 | MTARC1 | 0.269 | −0.077, 0.614 | |
| rs2250802 | GPAM | 0.263 | −0.087, 0.614 | |
| rs429358 | **APOE** | 0.252 | 0.075, 0.429 | 脂蛋白总多效性位点 |
| rs58542926 | TM6SF2 | 0.114 | 0.008, 0.219 | 机制为削弱 VLDL 分泌 |
| rs1229984 | ADH1B | −0.063 | −0.875, 0.748 | 酒精通路;冰岛 MAF 0.4%,无信息 |
| **rs738408** | **PNPLA3** | **−0.054** | −0.153, 0.045 | **最强、最特异的肝脂工具变量** |
| rs56252442 | MAST3 | −0.283 | −0.660, 0.094 | |

比值从 −0.28 横跨到 +1.05。对肝脂**最特异**的工具变量(PNPLA3、TM6SF2,纯肝细胞作用)
贴近 0;有**全身性脂质效应**的(TRIB1、APOE、GPAM、MTARC1)在 0.25–1.05。
TRIB1 对 CPN2 的关联(P = 6.3×10⁻¹⁰)甚至强于它对肝脂的关联 —— 典型水平多效性。

剔除 TRIB1 与 APOE 后,估计值 0.095 → 0.033,Q 从 49.3 → 11.4。
**全模型里那点正向漂移全部来自已知脂质多效性位点,不来自肝脏脂肪本身。**

> **需要如实报告的脆弱点**:leave-one-out 显示剔除 PNPLA3 后 β = 0.193、P = 0.050。
> 阴性结论在相当程度上依赖 PNPLA3。但 PNPLA3 恰是 F 最高(427)、效应最强
> (肝脂 P = 5×10⁻⁹⁵)、作用最局限于肝细胞的那一个;拿掉它后剩下的正是多效性最重的
> 一批。「剔掉唯一特异的工具变量后,一群多效性位点给出边缘显著」是多效性的表现,
> 不是因果的证据。

正向区域:chr3 CPN2 TSS(194,351,387,GRCh38)± 1 Mb。反向为全基因组。

所有数据源均为 **GRCh38 / 1-based**,无需 liftover。这一点是实测验证的,
不是只看元数据声明:用 PNPLA3 `rs738409`(GRCh37 = 22:44324727,GRCh38 = 22:43928847)
这类两 build 坐标不同的变异去对。

**为什么用 deCODE**:UKB-PPP、Sun_2018、eQTLGen 均无 CPN1/CPN2。eQTLGen 是下载
完整显著 cis-eQTL 表(1,050 万条、16,923 个基因)逐行核对的,以 ALB / IL6R /
CLEC12A 作阳性对照确认流程有效。缺席的原因是生物学的:两基因在肝细胞转录、
蛋白分泌入血,全血本身不表达。

> ⚠ **CPN1 在 SomaScan 平台上命名为 `CBPN`**,按基因名检索会漏掉。

## 工具变量

deCODE 附表 ST08 列出 6 个条件独立 cis-pQTL,过 MAF ≥ 0.01 后保留 3 个:

| rsID | Beta (SD) | SE | F | MAF | 备注 |
|---|---|---|---|---|---|
| rs3732477 | −0.4994 | 0.0071 | 4942 | 0.230 | **有相关蛋白改变变异(PAV)** |
| rs34225900 | +0.0744 | 0.0132 | 32 | 0.118 | indel,两库写法不同 |
| rs1466733 | +0.0495 | 0.0100 | 24 | 0.232 | |

两个关键问题,分析中已处理:

1. **rs3732477 占 IVW 约 98% 的权重**(单独解释血浆 CPN2 的 8.83% 变异,另两个各约 0.1%),
   且带 PAV,存在表位效应风险 —— SomaScan 靠适配体结合定量,氨基酸改变可能使
   适配体结合变弱、读数偏低,而蛋白实际含量未变。故另跑一版剔除它的敏感性分析。
2. **rs34225900 的等位基因表示法两库不一致**:deCODE 为 `chr3:194350491 TAATG/TAATT`
   (左补齐),FinnGen 为 `chr3:194350495 T/G`。差异位即 deCODE 串第 5 位,
   因此 deCODE 的 `TAATG` 对应 FinnGen 的 `G`。脚本中显式映射,未按位置盲配。

## 数据获取

本仓库**不包含数据**。`data/` 已在 `.gitignore` 中排除,原因与获取方式如下。

### 暴露端 · deCODE

deCODE 的数据使用协议规定 **"You will not redistribute the downloaded files."**,
因此原始文件与其区域切片均不入库。请自行获取:

1. 访问 <https://download.decode.is>,阅读并接受数据使用协议
2. 搜索 `CPN` ,下载 `6415_90_CPN2_CPN2.txt.gz`(909 MB)
3. 放到 `data/raw/`,并用同目录的 md5 校验(校验的是**解压后**的文件):
   ```bash
   gunzip -c data/raw/6415_90_CPN2_CPN2.txt.gz | md5
   ```
4. 切出 cis 区域(CPN2 TSS 194,351,387 ± 1 Mb):
   ```bash
   gunzip -c data/raw/6415_90_CPN2_CPN2.txt.gz \
     | awk -F'\t' 'NR==1 || ($1=="chr3" && $2>=193351387 && $2<=195351387)' \
     > data/exposure_CPN2_cis.tsv
   ```

> ⚠ CPN1 在 SomaScan 平台命名为 `CBPN`,对应 `7142_5_CPN1_CBPN.txt.gz`。

### 结局端 · FinnGen R12

公开可取,**无需下载完整的 800 MB 文件** —— 用 tabix 配远程索引只取所需区域:

```bash
brew install htslib          # 提供 tabix

B=https://storage.googleapis.com/finngen-public-data-r12/summary_stats/release
HDR=$'#chrom\tpos\tref\talt\trsids\tnearest_genes\tpval\tmlogp\tbeta\tsebeta\taf_alt\taf_alt_cases\taf_alt_controls'

for PH in NAFLD CIRRHOSIS_BROAD C3_HEPATOCELLU_CARC_EXALLC; do
  curl -sL -o "/tmp/$PH.tbi" "$B/finngen_R12_$PH.gz.tbi"
  { echo "$HDR"
    tabix "$B/finngen_R12_$PH.gz##idx##/tmp/$PH.tbi" 3:193351387-195351387
  } > "data/outcome_${PH}_cis.tsv"
done
```

`##idx##` 语法指定本地索引 + 远程数据,htslib 直接用 HTTP range 请求取对应字节区间。

反向 MR 的暴露端 A 需要**全基因组**的 FinnGen NAFLD,`R/04_reverse_mr.R` 用同样的
`##idx##` 机制按位点取,不落整份文件。

### 反向暴露端 B · UKB 肝脏脂肪(GWAS Catalog)

```bash
F=https://ftp.ebi.ac.uk/pub/databases/gwas/summary_statistics
curl -o data/raw/GCST90029073_liverfat_Haas2021.h.tsv.gz \
  "$F/GCST90029001-GCST90030000/GCST90029073/harmonised/34957434-GCST90029073-EFO_0010821.h.tsv.gz"
```

> ⚠ 必须取 `harmonised/` 下的 **`.h.tsv.gz`**(GRCh38)。同目录还有一个
> `-Build37.f.tsv.gz`,那是投稿时的原始 build,下错了坐标就全错。
> ⚠ `.h.tsv.gz` 里 `hm_*` 列与非 `hm_*` 列的**效应等位基因可能相反**,
> 混用两套列会让 beta 符号反过来(本文件首行:`hm_effect_allele=AC, hm_beta=+0.00336`
> 而 `effect_allele=A, beta=-0.00336`)。做法:等位基因、坐标、beta 全取 `hm_*`,
> SE 与 P 取非前缀列(`hm_*` 里没有 SE,且二者与方向无关)。

下好这一个文件即可 —— 工具变量提取(P < 5×10⁻⁸ → ±1 Mb 距离剪枝)与 deCODE 端查询
都由 `R/05_reverse_mr_liverfat.R` 自动完成并缓存到 `data/`,删掉缓存文件即重算。

## 运行

```bash
Rscript R/01_prepare_data.R          # 整理两端数据 + 等位基因频率交叉核对
Rscript R/02_run_mr.R                # 正向 MR:主分析与敏感性分析
Rscript R/03_coloc.R                 # 贝叶斯共定位
Rscript R/04_reverse_mr.R            # 反向 MR · A:FinnGen NAFLD → CPN2
Rscript R/05_reverse_mr_liverfat.R   # 反向 MR · B:UKB 肝脏脂肪 → CPN2
```

04 / 05 内已 `set.seed(42)` —— 加权中位数与加权众数内部用 bootstrap,不固定种子
每次结果会有微小漂移。

04 与 05 都需要扫一遍 deCODE 全基因组文件(909 MB,约 1–2 分钟),结果缓存在 `data/`,
再次运行直接读缓存。05 另需 `data/raw/` 下的 Haas 肝脂文件。

依赖:`TwoSampleMR` `coloc` `data.table`(r-universe:`https://mrcieu.r-universe.dev`)。
区域数据取用了 `tabix`(htslib)+ FinnGen 的远程 `.tbi` 索引,无需下载完整的 800 MB 文件。

## 已知限制

- 工具变量仅 3 个,MR-PRESSO 无法进行;剔除 PAV 后仅剩 2 个,MR-Egger 与加权中位数失效
- 剔除 PAV 后置信区间极宽(如 NAFLD:0.50–2.04),属功效不足,**不构成证伪**
- FinnGen 的肝硬化与肝癌 ICD 编码不区分病因,「非病毒非酒精」在公共数据层面无法切分
- NASH 在 FinnGen R12 仅 254 例,功效不足,已排除出分析
- 未纳入邻近的 **LRRC15**(距 CPN2 仅 3.8 kb,该位点信号强得多,是竞争解释),待补

反向 MR 特有的限制:

- **本机无 plink,用 ±1 Mb 距离剪枝代替 LD clumping**。chr19 上 rs56252442
  (18.12 Mb)与 TM6SF2(19.27 Mb)仅相距 1.15 Mb,理论上可能是同一信号被切成两个。
  两者 Wald ratio 方向相反(−0.283 vs +0.114),倾向确为独立信号,但最好用 LD 矩阵正式确认。
- **暴露端 B 的单位未经核实**。GWAS Catalog 元数据未声明肝脂的量纲;
  从效应量推断为**标准化后的 SD**(PNPLA3 每等位基因 0.195,若为绝对百分比则与
  已知效应量差一个数量级)。正式引用前需回 Haas 原文核。
- **反向暴露 A(FinnGen NAFLD)与正向结局同源**。Ghodsian 等更大的 NAFLD meta
  同样包含 FinnGen。这不产生偏倚(反向的结局端是 deCODE,两端无重叠),
  但 FinnGen 会同时出现在正向的结局端与反向的暴露端,应在正文中说明。
- **MR 测的是血浆总量,不是分配**。若疾病改变的是 CPN2 在游离态与 EV 结合态之间的
  比例而非总浓度,本文所有 MR 分析在结构上都看不到这种变化。
  区分二者需在同一批样本上同时测定血浆总 CPN2 与 EV 组分 CPN2。
